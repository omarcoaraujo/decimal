# Changelog

## 0.1.0 - 2026-10-27

- Read money amounts and exchange rates from text such as "123.45" and "5.1859338271045"
- Write amounts back as text, always with two decimals
- Add, subtract, compare and sum amounts without floating point errors
- Convert an amount with an exchange rate, rounding half up on the last cent
- Take a percentage of an amount
- Clear errors instead of a wrong result when a number is too large or has too many decimals
